# Signify - Real-Time Sign Language Translation Avatar

Signify is an accessibility tool that translates real-time spoken audio into 3D Sign Language animation. It works locally and integrates seamlessly with video conferencing tools (like Zoom) and web browsers.

## Live Deployments
- 🌐 **Landing Page:** [http://signify-landing-page-12345.s3-website-us-east-1.amazonaws.com](http://signify-landing-page-12345.s3-website-us-east-1.amazonaws.com)
- 📺 **LG TV App Preview:** [http://signify-tv-app-12345.s3-website-us-east-1.amazonaws.com](http://signify-tv-app-12345.s3-website-us-east-1.amazonaws.com)

## Overview
This repository contains:
- `website/`: The Next.js landing page.
- `website/lg_tv_app/`: The LG webOS TV application for broadcasting sign language translation.
- `chrome-extension/`: Browser extension for YouTube and Twitch integrations.
- `core/` & `gui/`: The standalone Windows executable code for local processing.

See `docs/README.md` for more detailed documentation, or `website/README.md` for the Next.js project.
