The Pipeline

01

Audio Interception

Using the WASAPI API, Signify captures high-fidelity system audio and microphone input directly at the OS level, completely bypassing generic web-audio limitations.

02

Instant Transcription

The dual audio streams are fed into an optimized speech-to-text pipeline, delivering lightning-fast English transcriptions with deep contextual awareness.

03

Grammar Translation

A local, specialized Natural Language Processing model restructures English sentences into accurate ASL syntax (Topic-Comment structure, facial expressions mapping).

04

Avatar Broadcast

The final translation triggers precise 3D bone animations. This visual stream is piped into Zoom as a seamless Virtual Camera.

Deployment Protocol

A frictionless setup process designed to get the accessibility engine running in under three minutes.

01

Install Virtual Camera

Signify relies on the OBS Virtual Camera driver to broadcast the avatar feed. Install OBS Studio and ensure the Virtual Camera component is enabled.

Download OBS Studio→
02

Launch Signify Engine

Run the standalone executable. The engine will automatically interface with WASAPI to capture system audio and initialize the local NLP models.

>.\Signify.exe --start-engine
03

Configure App

Join your meeting (Zoom, Teams). Select 'OBS Virtual Camera' as your video input. The avatar will automatically animate in real-time.
